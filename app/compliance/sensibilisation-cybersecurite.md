# Guide de Sensibilisation Cybersécurité - StratCyber

## Vue d'ensemble

Ce guide complet vous accompagne dans la mise en place d'un programme de sensibilisation cybersécurité efficace, basé sur les recommandations de l'ANSSI et les meilleures pratiques internationales.

> **Sources officielles** : [ANSSI - SecNumAcadémie](https://secnumacademie.gouv.fr) | [ANSSI - Guide d'hygiène informatique](https://www.ssi.gouv.fr/guide/guide-dhygiene-informatique/) | [ANSSI - Sensibilisation](https://www.ssi.gouv.fr/particulier/sensibilisation/)

---

## 1. Fondamentaux de la Sensibilisation Cyber

### 1.1 Pourquoi sensibiliser ?

**Statistiques clés** :
- 85% des cyberattaques impliquent un facteur humain
- 60% des violations sont causées par des employés négligents
- Le phishing représente 90% des attaques réussies
- ROI moyen de 5:1 sur les investissements en sensibilisation

**Objectifs de la sensibilisation** :
- Réduire les risques de sécurité liés au facteur humain
- Créer une culture de sécurité dans l'organisation
- Améliorer la détection et le signalement des incidents
- Respecter les obligations réglementaires (NIS2, ISO 27001)

### 1.2 Principes pédagogiques

**Apprentissage efficace** :
- Formation courte et régulière (microlearning)
- Contenu adapté au rôle et au contexte
- Mise en pratique immédiate
- Répétition et renforcement
- Mesure des résultats

## 5. Phishing Simulé

### 5.1 Stratégie de simulation

**Approche progressive** :
- **Phase 1** : Simulations évidentes (sensibilisation)
- **Phase 2** : Simulations moyennes (formation)
- **Phase 3** : Simulations sophistiquées (évaluation)

**Fréquence recommandée** :
- Mensuelle pour tous les utilisateurs
- Hebdomadaire pour les rôles critiques
- Après chaque formation théorique
- Suite à des incidents réels

### 5.2 Templates de phishing éducatif

**Modèle 1 : Mise à jour système**
```
Objet : [URGENT] Mise à jour de sécurité requise

Cher(e) collaborateur/trice,

Suite à une faille de sécurité détectée, une mise à jour 
critique de votre système est requise avant 17h aujourd'hui.

Cliquez ici pour effectuer la mise à jour : [LIEN_SIMULATION]

En cas de non-respect de cette procédure, votre accès 
pourra être suspendu pour des raisons de sécurité.

Service IT
```

**Modèle 2 : Notification RH**
```
Objet : Confirmation de présence - Formation obligatoire

Bonjour,

Vous êtes convié(e) à une formation obligatoire sur la 
nouvelle réglementation RGPD.

Date : [Date proche]
Lieu : Salle de conférence
Durée : 2h

Merci de confirmer votre présence : [LIEN_SIMULATION]

Attention : la non-participation entraînera une sanction.

Service RH
```

**Modèle 3 : Offre commerciale**
```
Objet : Offre exclusive - Matériel informatique -50%

Offre limitée dans le temps !

Équipez-vous avec du matériel professionnel 
à prix exceptionnel :
- Ordinateurs portables : -50%
- Écrans 4K : -40%  
- Imprimantes : -60%

Profitez-en maintenant : [LIEN_SIMULATION]

Plus que 24h pour en bénéficier !
```

### 5.3 Gestion post-simulation

**Processus de traitement** :

1. **Clic détecté** → Page éducative immédiate
2. **Formation automatique** → Module adapté au piège
3. **Suivi personnalisé** → Manager informé si récidive
4. **Formation renforcée** → Session individuelle si besoin

**Page éducative post-clic** :
```html
🎣 SIMULATION DE PHISHING

Vous venez de cliquer sur un lien dans une simulation de phishing.

❌ Ce que vous avez fait :
- Cliqué sans vérifier l'expéditeur
- Ignoré les signaux d'alerte
- Agi sous la pression temporelle

✅ Ce que vous devriez faire :
1. Vérifier l'adresse de l'expéditeur
2. Analyser le contenu (urgence, menaces)
3. Valider auprès de l'expéditeur supposé
4. Signaler l'email suspect

📚 FORMATION RECOMMANDÉE
Un module de formation vous a été attribué automatiquement.

Cette simulation vise à vous protéger contre de vraies attaques.
```

## 9. Conformité Réglementaire

### 9.1 Exigences NIS2

**Article 21 - Sensibilisation** :
- Formation régulière du personnel
- Sensibilisation aux cybermenaces
- Bonnes pratiques de cyberhygiène
- Procédures de signalement

**Programme conforme NIS2** :
- Formation initiale obligatoire
- Mise à jour annuelle minimum
- Évaluation des connaissances
